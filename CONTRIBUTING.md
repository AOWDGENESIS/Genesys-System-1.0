# Contributing

- Describe the problem and provide minimal reproduction steps.
- Remove personal data, credentials, API keys, and private project files from issue attachments.
- Include tests for validation rules, file handling, installer behavior, and data preservation where applicable.
- Do not claim platform or legal compliance solely because a validator passes.
- Record Python and Windows versions for test results.
- Do not publish releases until the build, tests, security review, and release notes have been checked.
